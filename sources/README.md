## دربارهٔ منابع

- اسناد PDF و DOCX در قالب اصلی خود نگه داشته شده‌اند؛ محتوای آن‌ها جایگزین یا بازنویسی نشده است.
- بعضی فایل‌ها فهرست پرسش دارند و بعضی دیگر پاسخ، توضیح، مثال کد یا یادداشت‌های چند حوزه را هم شامل می‌شوند.
- محتوای READMEها یک فهرست تمرینی موضوعی است، نه رونویسی صفحه‌به‌صفحه از همهٔ اسناد.

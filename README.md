# مجموعه پرسش‌های مصاحبه برنامه‌نویسی

پرسش‌های اسناد اولیه بر اساس موضوع مرتب شده‌اند تا بتوانید برای مصاحبه‌های .NET و Full-Stack مرحله‌به‌مرحله تمرین کنید. پرسش‌های هم‌معنی تا حد امکان ادغام شده‌اند؛ فایل‌های اصلی برای مراجعه و بررسی متن کامل در پوشهٔ `sources/` نگه‌داری شده‌اند.

## شروع سریع

1. از [راهنمای پرسش‌ها](./questions/README.md) موضوع موردنظر را انتخاب کنید.
2. برای آمادگی API، مجموعهٔ [۱۰۰ پرسش مصاحبهٔ API](./questions/api/README.md) را ببینید؛ برای آمادگی .NET هم از [ASP.NET Core و Web API](./questions/dotnet/README.md) و [C#](./questions/csharp/README.md) شروع کنید.
3. بعد به [پایگاه‌داده و EF Core](./questions/data/README.md)، [معماری و طراحی](./questions/architecture/README.md) و سایر موضوع‌ها بروید.
4. برای مشاهدهٔ اسناد کامل و اصلی، [فهرست منابع](./sources/README.md) را ببینید.

## پوشه‌ها

- [`questions/`](./questions/README.md) — پرسش‌های مرتب‌شده و آمادهٔ تمرین، در فایل‌های README موضوعی
- [`sources/`](./sources/README.md) — اسناد PDF و DOCX اصلی، دسته‌بندی‌شده بر اساس موضوع

## روش استفاده

- پاسخ هر پرسش را ابتدا بدون مراجعه به منبع توضیح دهید؛ سپس برای تکمیل پاسخ به سند اصلی رجوع کنید.
- پرسش‌های دارای عبارت‌هایی مانند «چگونه پیاده‌سازی می‌کنید؟» را با مثال واقعی یا کد تمرین کنید.
- این مجموعه پاسخ‌نامه نیست؛ فایل‌های منبع بعضاً شامل پاسخ و توضیح‌اند و در فهرست منابع معرفی شده‌اند.

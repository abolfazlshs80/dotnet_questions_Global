# معماری نرم‌افزار و الگوهای طراحی

## اصول طراحی و OOP

1. What are the five SOLID principles? Give a practical example of each.
2. How do encapsulation, abstraction, inheritance, and polymorphism improve a design?
3. What is dependency inversion, and how does dependency injection help implement it?
4. What is the difference between dependency injection and the Service Locator pattern?
5. What is the difference between a layered architecture and Clean Architecture?
6. What are the responsibilities of the layers in Clean Architecture?
7. What is the difference between a monolith and microservices?
8. How would you decide whether a component should become a separate microservice?
9. How would you migrate a monolith to microservices incrementally?
10. How can services coordinate reliably in an event-driven system?
11. What are CQRS and the Saga pattern, and when might they be useful?
12. What is an Aggregate Root in Domain-Driven Design?

## الگوهای طراحی

13. What is a design pattern, and how do creational, structural, and behavioral patterns differ?
14. How does the Singleton pattern work, and what are its risks in an application using dependency injection?
15. What is the difference between Factory Method and Abstract Factory?
16. What problem does the Repository pattern solve?
17. When is Unit of Work useful?
18. How does the Strategy pattern make algorithms interchangeable?
19. What is the difference between the Decorator and Proxy patterns?
20. How does the Observer pattern support event notification?
21. What are the Adapter, Facade, Builder, and Command patterns used for?
22. Which design patterns have you used in a real project, and what trade-offs did they introduce?

## API و طراحی سامانه

23. What are REST constraints, and what makes an API RESTful?
24. What are the differences between `GET`, `POST`, `PUT`, `PATCH`, and `DELETE`?
25. What are DTOs, and why should an API avoid exposing persistence entities directly?
26. What is the difference between REST and GraphQL?
27. How do you design for scalability and resilience?
28. What are the advantages and disadvantages of microservices?

# پایگاه‌داده، SQL Server و EF Core

## SQL و طراحی داده

1. What are the different types of SQL joins? Explain `INNER`, `LEFT`, `FULL`, and self joins.
2. What is the difference between `WHERE` and `HAVING`?
3. What are primary, unique, candidate, and composite keys?
4. What is the difference between clustered and non-clustered indexes?
5. How do indexes improve query performance, and what are their trade-offs?
6. What is the difference between `DELETE`, `TRUNCATE`, and `DROP`?
7. What are normalization and denormalization?
8. What are stored procedures, views, functions, triggers, and CTEs?
9. What is the difference between a temporary table and a table variable?
10. How do transactions work, and how would you handle rollback and timeouts?
11. How would you find the second-highest or Nth-highest salary?
12. How would you count employees in each department?
13. What is the difference between SQL and NoSQL databases?
14. How would you diagnose and optimize a slow SQL query?

## Entity Framework Core

15. What is the difference between `DbContext` and `DbSet`?
16. What are EF Core migrations, and how would you apply them in a CI/CD pipeline?
17. How do you configure one-to-many and many-to-many relationships?
18. What are navigation properties?
19. What are eager, explicit, and lazy loading?
20. What does `AsNoTracking()` do, and when should it be used?
21. How does EF Core translate LINQ expressions into SQL?
22. What is the difference between `FirstOrDefault()` and `SingleOrDefault()` in an EF query?
23. How do you handle concurrency conflicts in EF Core?
24. How does cascade delete work?
25. What are shadow properties, value converters, and global query filters?
26. What is the purpose of `AsSplitQuery()`?
27. How would you optimize EF Core queries for a large dataset?
28. How do you manage transactions in EF Core?
29. What are the trade-offs of using the Repository or Unit of Work patterns with EF Core?

# راهنمای پرسش‌ها

پرسش‌ها بر پایهٔ حوزهٔ مصاحبه دسته‌بندی شده‌اند. متن انگلیسی پرسش‌ها در مواردی که منبع انگلیسی بوده حفظ شده است تا با صورت رایج آن‌ها در مصاحبه آشنا بمانید.

| موضوع | محتوای اصلی |
|---|---|
| [مصاحبهٔ API](./api/README.md) | ۱۰۰ پرسش مقدماتی، متوسط، پیشرفته و سناریومحور دربارهٔ API |
| [ASP.NET Core و Web API](./dotnet/README.md) | Middleware، DI، پیکربندی، امنیت API، میزبانی و کارایی |
| [C# و .NET](./csharp/README.md) | زبان C#، حافظه، async، LINQ و مبانی شیءگرایی |
| [پایگاه‌داده و EF Core](./data/README.md) | SQL Server، طراحی پرس‌وجو، تراکنش و Entity Framework |
| [معماری و الگوهای طراحی](./architecture/README.md) | SOLID، Clean Architecture، الگوها و Microservices |
| [فرانت‌اند](./frontend/README.md) | JavaScript، Angular، React، مرورگر و UI/UX |
| [DevOps و ابزارهای تیمی](./devops/README.md) | Git، CI/CD، Azure، Docker و Kubernetes |
| [کیفیت، امنیت و مهارت‌های مصاحبه](./engineering/README.md) | تست، امنیت، کارایی، حل مسئله و پرسش‌های رفتاری |

1. مبانی C# و OOP
2. اصول API و HTTP
3. ASP.NET Core و Web API
4. SQL و EF Core
5. معماری، SOLID و الگوهای طراحی
6. تست، امنیت، کارایی و استقرار
7. تمرین پرسش‌های رفتاری و سناریوهای عملی

پرسش‌های تکراری یا بسیار نزدیک در چند سند، در این فهرست تا حد امکان یک‌بار آورده شده‌اند. برای مشاهدهٔ نسخهٔ کامل و متن اصلی به پوشهٔ [`sources/`](../sources/README.md) مراجعه کنید.

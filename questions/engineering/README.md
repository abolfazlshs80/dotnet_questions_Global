# کیفیت، امنیت، کارایی و مهارت‌های مصاحبه

## تست و کیفیت

1. What is the purpose of a unit test?
2. What is the difference between a mock, stub, and fake?
3. When should you use an integration test instead of a unit test?
4. How would you test an integration that depends on an external service?
5. What is Test-Driven Development, and what are the Red-Green-Refactor steps?
6. How would you choose meaningful tests rather than optimizing only for coverage?

## امنیت

7. What is the difference between authentication and authorization?
8. How do HTTPS and TLS protect data in transit?
9. How would you prevent XSS and CSRF attacks in a web application?
10. How should JWTs and refresh tokens be stored, validated, and expired?
11. How do you protect an API from overposting and invalid input?
12. What sensitive information should never appear in application logs?

## کارایی و عیب‌یابی

13. How would you investigate a slow API endpoint?
14. How would you find a memory leak in a .NET application?
15. What tools would you use to profile or benchmark code?
16. What is the difference between caching and buffering?
17. How would you improve a slow database-backed page with a large result set?
18. How do you distinguish a CPU bottleneck from an I/O bottleneck?
19. How would you improve the scalability of a .NET application?

## حل مسئله و رفتار حرفه‌ای

20. Describe a challenging bug you fixed and how you investigated it.
21. How do you handle a new or changing requirement from a customer?
22. How do you prioritize work when facing a tight deadline?
23. Describe a disagreement or conflict within a team and how you resolved it.
24. How do you mentor junior developers or review their code?
25. What was a difficult technical decision in one of your projects, and what trade-offs did you consider?
26. Walk through a production issue you diagnosed, from symptoms to prevention.

## تمرین عملی

27. Reverse a string in C#.
28. Write a LINQ query that paginates a collection using `Skip()` and `Take()`.
29. Write a SQL query to return the second-highest salary.
30. Given a slow API, explain the steps you would take before changing code.
